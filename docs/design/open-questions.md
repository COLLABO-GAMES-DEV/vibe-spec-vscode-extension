# 남은 질문

[문서 지도](README.md)

확정된 Key·경로·수천 행 목표·동시 수정 범위·복구 방식은 다시 질문하지 않는다.

| 질문 | 정할 시점 |
| --- | --- |
| 실제 이관의 다중 표·Key·병합 빈칸·충돌값을 어느 구조와 의미로 옮길 것인가? | 시험 결정 목록을 사람이 검토 |
| 기존 importer 축소·삭제 범위는? | [미확정 제안](decisions.md#검토-제안--아직-확정하지-않은-부분)을 사람이 결정 |
| 목록·표를 개별 문서 대안 범위로 다뤄야 하는가? | 첫 구현 밖; 필요가 생기면 별도 설계 |
| 전달 태그·여러 쟁점을 동시에 적용하는 UX는? | 후속 범위에서 보완 |
| 레벨링 모델·허용 조정·계산 결과의 표현은? | 3단계에서 보완 |
