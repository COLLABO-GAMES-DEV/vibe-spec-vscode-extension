# 0.10.0 — 복제와 자유 편집

전용 A/B·기획 상태·확정 기능을 제거하고 일반 표·문서로 비교한다. 사이드바의 표·문서를 우클릭하고 **복제**를 선택하면 이름을 입력받아 같은 폴더에 독립 복제본을 만들고 새 탭을 연다.

- 표는 스키마도 복제하므로 복제본의 열 설정과 원본이 분리된다. 행 순서·숫자 문자열·메모를 유지한다.
- 문서는 BOM·CRLF·공백·지원 밖 구문을 포함한 저장 원문을 그대로 복사한다. 원본 문서에 초안이 있으면 먼저 저장하거나 버리도록 안내한다.
- 참조 열의 대상·문서 링크는 원본과 같은 대상을 유지한다. 문서 안에 A안·B안 제목을 두는 것도 일반 편집이다.
- CLI는 `duplicate table|document <name> --to <new-name> --expect-revision <revision> [--dry-run] --json`을 제공한다. 기존 `--target base`는 선택적 호환 인자다. 대안 target과 전용 `plan` 명령은 거절한다. 이관용 `import plan/apply`는 유지한다.
- 기획 비교 섹션·문서 대상/범위 선택·기준안 배너와 대안 합성·검증·참조 갱신 엔진 및 전용 테스트를 제거했다. 문서의 일반 저장·원문 보존·외부 변경 감지·참조·Git 충돌 기능은 유지한다.

## 기존 데이터와 안내

`plans/`는 삭제·자동 변환·합치기하지 않는다. 관리·검증·포맷·이름 변경·저장 대상에서 제외하고 기존 Git 이력을 보존한다. 필요한 내용을 일반 표·문서로 옮기는 작업은 별도 사용자 결정이다. 실제 시험 기획 폴더는 이번 작업에서 변경하지 않았다.

새 `init`의 AGENTS.md와 공통 이관 스킬은 복제·자유 편집을 안내한다. 기존 기획 폴더의 안내 파일은 자동 덮어쓰지 않는다. 기존 에이전트가 옛 plan 명령을 시도하면 새 CLI의 도움말과 이 설계 변경을 확인하고 안내를 갱신해야 한다.

## 검증

core·CLI는 복제 원문·독립 스키마·이름 충돌·stale revision·dry-run·참조 삭제 보호와 기존 plans/ 보존을 검사한다. Git 저장은 복제본을 커밋하면서 별도로 staged된 옛 plans/ 파일은 제외하고 보존한다.

실제 VS Code 검사는 우클릭 메뉴 등록·도메인 안 생성·새 탭 열기·초안 복제 차단을 포함한다. Playwright는 복제 후 독립 편집, 무변경 저장, 수정 블록 바깥 원문과 일반 표·문서 회귀를 확인한다. Windows 전체 CI도 출시 전에 수동 실행하며 재시도로 실패를 숨기지 않는다.

설계는 [d30](../design/decisions.md#d30)과 [복제 계약](../design/comparison.md)에 있다. Marketplace 게시와 main 병합은 이번 작업에 포함하지 않는다.
